### Exploration of News Sources
This folder contains code exploring and comparing different data sources of news articles, which are:

- GNews (https://github.com/ranahaani/GNews?tab=readme-ov-file#Get-news-by-geo-location)

- NewsAPIorg (https://newsapi.org/)

The jupyter notebooks contain the code to execute queries for multiple test cases. 
The utilities file contains functions created to query GNews.
Note that given the functional limitations of the tools/free versions, not all test cases could be tested.
